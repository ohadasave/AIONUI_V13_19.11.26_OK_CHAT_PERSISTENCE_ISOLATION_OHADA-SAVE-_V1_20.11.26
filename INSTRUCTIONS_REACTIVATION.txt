ÉTAPE 2 : Ouvrir DevTools

   config['security.loginEnabled'] = true;

   localStorage.removeItem('eaudit_logged_in');
   localStorage.removeItem('eaudit_login_time');

🆘 PROBLÈMES COURANTS
─────────────────────

❌ La page de login ne s'affiche pas

   Solution : Nettoyer complètement le localStorage
   
   1. Ouvrir DevTools (F12)
   2. Dans Console, taper :
   
      localStorage.clear();
      location.reload();


❌ Écran blanc au démarrage

   Solution : Nettoyer le cache
   
   1. Fermer l'application
   2. Dans PowerShell :
   
      Remove-Item -Recurse -Force out/, dist/ -ErrorAction SilentlyContinue
      npm run start


❌ Les identifiants ne fonctionnent pas

   Note : Le système actuel accepte N'IMPORTE QUEL email et mot de passe.
   Les identifiants fournis sont recommandés mais pas obligatoires.
