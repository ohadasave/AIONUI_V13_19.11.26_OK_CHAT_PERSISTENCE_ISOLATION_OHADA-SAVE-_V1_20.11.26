Utilisez la fonction recherche de votre éditeur:

- `Ctrl+F` (Windows/Linux)
- `Cmd+F` (Mac)

**Mots-clés fréquents**:
- `authentication` → erreurs de connexion GitHub
- `conflict` → problèmes de merge
- `submodule` → problème py_backend
- `remote` → configuration origin/backup
- `commit` → conventions et bonnes pratiques
- `error` → troubleshooting
