## 🚀 LANCER L'APPLICATION

### Méthode 1 : Via npm (RECOMMANDÉ)

Ouvrez **un nouveau terminal PowerShell** et exécutez :

```powershell
cd G:\Aionui_client
npm run start
```

**L'application Electron devrait s'ouvrir.**

### Méthode 2 : Via npx

Si la méthode 1 échoue :

```powershell
cd G:\Aionui_client
npx electron-vite dev
```

### Méthode 3 : WebUI

Pour lancer uniquement l'interface web :

```powershell
cd G:\Aionui_client
npm run webui
```

Puis ouvrir dans votre navigateur : **http://localhost:25808**

## 🆘 SI PROBLÈMES

### Erreur "electron-vite not found"

```powershell
# Ouvrir un NOUVEAU PowerShell et réessayer
cd G:\Aionui_client
npm run start
```

### Erreur TypeScript

```powershell
bunx tsc --noEmit
# Puis relancer
npm run start
```

### Port déjà utilisé (WebUI)

```powershell
# Tuer le processus sur port 25808
Get-Process -Name node | Stop-Process -Force
# Puis relancer
npm run webui
```

### Rebuild Electron

```powershell
npm rebuild electron
npm run start
```
